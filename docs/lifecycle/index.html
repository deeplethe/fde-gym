02 / Opt-in integration

One invocation.
A defined lifetime.

− subprocess.run([python, ...])+ run_delivered([python, ...])

The case grader opts into the callback. A trusted bootstrap records the delivered interpreter's identity; cleanup identifies descendants, freezes and terminates the family, and verifies termination before grading continues.

Requires macOS 15.4 or later with working original-parent identity support. Unsupported kernels fail closed before delivered code runs. Other hosts need a supported containment backend.

Read the invocation contract ↗Reproduction commands and pinned inputs ↗
Scope and limitations

This opt-in callback protects the selected case invocations. Unobserved intermediates, PID reuse races, and supervisor termination remain limitations. The recorded probe did not improve its score. Complete OS containment, other cases, and production deployment are not established by these results.
